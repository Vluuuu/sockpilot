# Code of Conduct

We want SockPilot to be a useful and respectful open-source community.

Please be considerate, constructive and professional in issues, discussions, pull requests and reviews. Harassment, discrimination, threats, doxxing, or posting other people's credentials or private information is not acceptable.

Maintainers may moderate or remove harmful content and restrict participation when necessary. For sensitive reports, use the private reporting process in [SECURITY.md](SECURITY.md).

This project welcomes contributions regardless of experience or background.
